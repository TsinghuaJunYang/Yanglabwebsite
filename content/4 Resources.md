## Data Sets

### 1. Global urban tree species occurrence data
This data set contains 159,845 occurrence records of tree species in 8,349 cities and 139 countries. It is the largest collection of urban tree species records in global cities so far. Rigorous procedures have been developed to validate the data. Please send us comments if you find any issues with the data. 

**Data link**: https://doi.org/10.6084/m9.figshare.26970220.

**Citations**:  Yang, X., Yan, P., Jin, J. _et al._ Global Urban Tree Species (GUTS): Revealing tree species diversity across the world’s urban areas. _Sci Data_ **13**, 485 (2026). https://doi.org/10.1038/s41597-026-06868-2

### 2. Global urban NbS parameters data
This data set contains data collected from 241 studies on methods and parameters used to quantify the benefits of nature-based solutions globally.  

**Data link:** https://data.tpdc.ac.cn/zh-hans/data/911366f9-3d9f-419e-822e-547f42ef2077

**Citations:** Ma, Y., Yang, J. 2025. A review of methods for quantifying urban ecosystem services. _Landscape and Urban Planning_, 253, 105215. https://doi.org/10.1016/j.landurbplan.2024.105215
